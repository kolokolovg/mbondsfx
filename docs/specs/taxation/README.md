# Спецификации налогооблагаемой базы и НДФЛ (core/application)

Нормативные целевые спецификации расчета налогооблагаемой базы (Taxable Base) и НДФЛ по купонам,
амортизации и погашению облигаций. Утвержденные версии не перезаписываются: изменения оформляются новой
версией. Статус спецификации не доказывает ни согласования, ни реализации. Реализация начинается только
после обновления AGENTS.md (см. раздел 11 версии).
