# MOEX Bonds FX

Модульный проект на Java 25 для явной модели облигаций, расчетов денежных потоков, учета портфеля
и подключения источников рыночных данных. Текущая точка запуска — командная строка для сборки
конфигурации приложения; графического интерфейса и полноценного пользовательского рабочего процесса
пока нет.

Источники данных — MOEX и ЦБ РФ; хранение пока только в памяти. Расчеты требуют явных входных
данных: налоги и тарифы автоматически не рассчитываются, поддержка купонных формул ограничена.

## Быстрый старт

Требуется JDK 25; Gradle 9.8.2 запускается через включенный в проект Wrapper. Установите `JAVA_HOME`
либо убедитесь, что Gradle обнаруживает установленный JDK.

```bash
./gradlew build  # сборка и тесты
./gradlew run
```

Запуск создает конфигурацию с провайдерами MOEX, ЦБ РФ и хранилищем в памяти, но не загружает
рыночные данные и не открывает пользовательский интерфейс.
