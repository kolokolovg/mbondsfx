# Сторонние лицензии

Тексты лицензий зависимостей, на которые ссылается [NOTICE](../NOTICE). Файлы в UTF-8 с LF;
юридические формулировки не изменялись, только имена и форматирование (HTML JaCoCo преобразован в текст).

| `JUnit-LICENSE-notice.txt` | EPL-2.0 notice | JUnit Jupiter |

| `MIT-jopt-simple.txt` | MIT | jopt-simple |
